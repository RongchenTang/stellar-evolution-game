## v0.2.0 — 2026-09-14

对应功能提交：`e25aa93`。

### 课件显示与手机适配
- 打开课件后收起班级星图与其他外围内容，让课件占满主要屏幕。
- 顶部保留返回星图按钮；回到星图不会主动清除课件进度。
- 使用动态视口高度适配手机浏览器，缩小边距并调整章节导航与操作按钮布局。
- 取消课件页面禁止缩放的设置，允许浏览器缩放。
- 切换关卡时回到课件内容顶部，从知识介绍开始阅读；同一关内填写词条不会强制回顶。

### 第二关：主序星平衡小游戏
- 放大操作区文字和数值，进度条高度由10px增加至24px。
- 开始挑战与按住加热按钮增大，最小高度66px，字号22px。
- 手机端将压力标签、数值与进度条分行排列。
- 游戏操作区禁止文字选择、复制、长按菜单和拖动文字；不影响寄语输入区。
- 加热按钮增加失去指针捕获、失焦后的释放处理，并支持空格及回车按住操作。
- 本次没有调整时间、初始稳定度或压力变化等难度参数。

### 第三关：恒星中年危机
- 游戏区主要文字改为白色，并增大2px，包括待选词条和已选步骤。
- 错误提示保留警示色，便于辨识。

### 验证与使用提醒
- JavaScript语法检查及Git差异检查通过。
- GitHub Pages发布成功，已检查线上新样式与课件显示逻辑文件。
- 尚未完成本轮手机实机验收；建议正式上课前完整试玩。
- 刷新网页即可加载更新，不要清除浏览器数据，以免丢失匿名学生身份。
- 本次仅更新`stellar-cloud/`，没有覆盖根目录原游戏，也没有修改云端数据库结构。

## v0.1.0 — 2026-09-11

对应功能提交：`e42df70`。

### 首次发布云端实验版
- 使用GitHub Pages托管网页，Supabase提供身份与课堂数据服务。
- 教师邮箱登录后创建课堂；学生匿名登录，凭课堂码加入。
- 每个课堂提供6×6星区，最多36人，学生自由选格并命名恒星。
- 栽种时锁定位置及初始质量，课件保留吸积调整与五关学习流程。
- 结局后提交最终质量和寄语，星图每5秒自动刷新。
- 同一课堂内，上下左右相邻、初始质量均为1—8 M☉且均完成登记的恒星自动匹配双星。
- 每颗恒星只匹配一次，优先匹配最早完成登记且尚未配对的相邻恒星。
- 提供占位冲突、重复提交与课堂访问权限检查。

### 已验证与已知限制
- 云端接口测试验证了前后相邻配对、质量边界1与8、重复登记不覆盖、学生无法删除课堂和非成员无法读取课堂。
- 同步方式是定时请求，不是WebSocket实时订阅。
- 游戏质量由网页上报，适用于课堂互动，不是防作弊考试系统。
- 清除浏览器数据可能丢失匿名身份；暂不支持自动增加第二星区。
- 双星是课堂互动情境，相邻位置并不代表真实双星形成或必然发生Ia型超新星。
