# 云端星图：数据库初始化

实验网页已接入接口，尚未发布或完成双设备验收。用 HTTP/HTTPS 访问 index.html，不要以 file:// 打开。

教师账号：在 Supabase Authentication → Users → Add user → Create new user 中创建邮箱/密码用户。若界面提供自动确认邮箱选项，请为你自己的测试账号启用。密码只由教师保管，不要发送到聊天。学生通过匿名身份进入，不需要注册。

本地预览：在项目根目录运行 python -m http.server 8765 --bind 127.0.0.1，然后打开 http://127.0.0.1:8765/stellar-cloud/ 。网页登录组件需要能访问 jsDelivr。

教师登录后创建课堂并分发课堂码，学生选位置、进入课件，结局页点击宇宙登记，返回星区填写寄语并提交。课件继承自由章节导航，不用于防作弊测验。多个班级使用不同课堂，不支持同一课堂自动增设第二星区。

1. 在 Supabase 项目中打开 SQL Editor，点击 New query。
2. 复制同目录 setup.sql 的全部内容，粘贴并点击 Run。
3. 执行成功后应显示 Success。脚本只需执行一次；重复执行会报告对象已存在，不要自行删除已有表。
4. 把成功提示或错误信息告诉我，以便继续前端接入及双设备测试。

脚本新增 stellar_private 私有 schema、classrooms 与 members 两张表，以及 public.stellar_classroom 接口。不删除已有业务数据。

教师通过邮箱登录创建课堂，匿名学生凭课堂码加入。数据表不开放直接读写；接口根据登录身份检查课堂成员资格。学生无法删除课堂、替他人提交或直接设置配对结果。

每课堂固定36人、6×6位置；位置与初始质量在首次栽种时锁定。相邻为上下左右，双方初始质量均在1至8之间且均完成登记后自动匹配。每个课堂的操作用数据库事务锁串行处理，避免抢位和重复配对。已完成登记的重复提交不再改变结果。

本版是课堂互动而非防作弊考试：质量仍由网页上报。匿名身份保存在浏览器中，清除浏览器数据后不能自动找回原身份。课堂码仅分享给本班；只填写恒星昵称和非敏感寄语。上线前需要配置匿名注册防滥用措施并在校园网验证。

后续先以短间隔自动刷新验证跨设备同步，再决定是否接入 WebSocket 实时订阅。数据库尚未实测；需验证跨课堂隔离、占位冲突、上下左右配对、重复提交以及教师权限。
